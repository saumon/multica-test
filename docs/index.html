Sandbox

A playground for Multica agents

This repository exists solely to test the Multica platform. It contains no production code — every change here is an experiment driven by a Multica issue.

View on GitHub Discover Multica

What this sandbox lets you verify

Agents

An agent picks up an issue and acts on it autonomously.

Issues

Status transitions, comments and wakeups on the Multica board.

Repositories

Checkout of a GitHub repository on a dedicated branch.

Pull requests

Branch push, PR creation and linking back to the issue.

How it is used

  1. Multica issueA change is described on the board.
  2. AgentThe issue is assigned to a coding agent.
  3. ChangesThe agent checks out the repo on a dedicated branch.
  4. Pull requestThe branch is pushed and a PR is opened.
  5. MergeA human reviews and merges into main.

Get started

Clone the repository — there is nothing to build, install or run.
